\chapter{The Procedural Sound Shim Architecture}
\label{ch:shims}

Having established the pitch groups of Chapter~\ref{ch:group-theory} and the DSP primitives of Chapter~\ref{ch:waveforms-dsp}, we now assemble the core synthesis abstraction of B-Sound: the \textbf{Sound Shim}, its 32-program General MIDI registry, and its 48-slot loudness-decay voice allocator.

\section{Formal Definition and Zero-Byte Lifecycle}

\begin{definition}[Sound Shim]
A \emph{Sound Shim} $S(t_0, \mathbf{p})$ is a stateless procedural synthesis routine parameterized by an exact trigger timestamp $t_0$ and a finite parameter vector $\mathbf{p} = (f, v, d, \dots)$ that generates a finite-duration acoustic signal via partial superposition (Equations~10--11):
\begin{equation}
\label{eq:shim-def}
y(t) = \sum_{k=1}^{K} A_k(t - t_0)\cdot W_k\!\big(2\pi f_k(t - t_0) + \phi_k\big) * h_k(t),
\end{equation}
where $W_k$ is a canonical oscillator or deterministic noise primitive, $h_k$ is the impulse response of an optional biquad filter, $*$ denotes convolution, and $A_k$ is an exponential ADSR envelope:
\begin{equation}
\label{eq:shim-env}
A(t) = V_{\mathrm{peak}} \cdot e^{-(t - t_{\mathrm{attack}})/\tau}.
\end{equation}
\end{definition}

In the Web Audio prototype, every transient oscillator registers into a disposal list via \texttt{registerTrackOsc(osc)}; stopping or switching tracks invokes \texttt{osc.stop(0)} and \texttt{osc.disconnect()} across the list to prevent garbage-collection leaks. In the native C99 runtime (\texttt{lilcu64\_wa.c}), oscillators draw strictly from a static voice pool with zero \texttt{malloc()} calls.

\section{The Immutable 32-Program Registry (\texttt{PROG[32]})}

In \emph{Orchestra}, a \emph{Program} is not a multi-megabyte soundbank; it is an immutable call-site descriptor mapping 32 selected General MIDI numbers onto existing shims, clef indicators (\texttt{tr}/\texttt{bs}), track polyphony ceilings $p$, and program-level transpositions $\mathrm{tr}$.

The remaining 96 General MIDI program numbers are intentionally undefined: requesting an unmapped number increments \texttt{refuse\_program} and leaves the track's current instrument untouched. There is no special MIDI Channel~10 drum map—percussion is selected explicitly by program number (`47` Timpani, `116` Kick, `117` Snare, `118` Hat, `119` Ind.\ Kick), which frees Channel~10 in the philharmonic template for the French Horn (Program~60).

Three percussion shims (`Snare`, `Hat`, `Ind.Kick`) repurpose the velocity argument to switch articulation: velocity $\ge 110$ triggers a rimshot on `shimSnare` ($220 \to 143\,\text{Hz}$ + BP $3.2\,\text{kHz}$ crack), and velocity $\ge 100$ opens `shimHiHat` from $0.055\,\text{s}$ to $0.28\,\text{s}$.

\section{48-Slot Voice Allocation and Loudness-Decay Stealing}

The DAW maintains a static pool \texttt{s\_slot[48]} where each slot represents one active MIDI note (distinct from the synthesizer's internal 48-oscillator pool; an 8-oscillator \texttt{shimSwarmatron} note occupies exactly one DAW slot).

When a new note arrives at sample position $n_{\mathrm{pos}}$, each occupied slot triggered at sample $t_0$ with initial gain $g$ is ranked by an exponential loudness proxy with time constant $\tau = 1\,\text{s}$ (Equation~9):
\begin{equation}
\label{eq:voice-proxy}
\mathrm{proxy}(\mathrm{slot}) = g \cdot \exp\!\left(-\frac{n_{\mathrm{pos}} - t_0}{f_s}\right).
\end{equation}

Allocation follows a strict three-tier deterministic policy:
\begin{enumerate}[leftmargin=1.5em]
  \item \textbf{Per-Track Ceiling:} If the track already holds $\ge \texttt{poly\_max}$ slots, steal the slot on that same track minimizing $\mathrm{proxy}(\mathrm{slot})$.
  \item \textbf{Free Pool Scan:} Otherwise, allocate the lowest-indexed free slot in \texttt{s\_slot[0..47]}.
  \item \textbf{Global Steal:} If all 48 slots are occupied, steal the globally quietest slot across all tracks and increment \texttt{steal\_voice} (suppressed during offline WAV export).
\end{enumerate}

\begin{remark}[One-Shot Expiry vs.\ Note-Off]
Nine percussive and chime rows (`47` Timpani, `80` Pulse, `102` Dance, `103` Zap, `112` Chime, `116` Kick, `117` Snare, `118` Hat, `119` Ind.\ Kick) set \texttt{shot = 1}. One-shot voices ignore MIDI Note-Off messages and are reclaimed solely upon expiry by \texttt{slots\_expire()}, preventing short pencil edits from truncating natural drum or cymbal decay.
\end{remark}
